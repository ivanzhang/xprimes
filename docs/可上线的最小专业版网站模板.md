# 三、部署（最简单路径）

## 方法一：Vercel（推荐）

```bash
npm install
npm run build
```

然后：

1. 上传到 GitHub
2. 登录 vercel.com
3. 一键导入项目
4. 绑定域名 xprimes.cn

---

## 方法二：本地测试

```bash
npm run dev
```

打开：

```
http://localhost:3000
```
