# 一、核心原则（先理解再写）

这个页面要做到三点：

### 1）欢迎质疑（不是对抗）

❌ “我们是对的”
✅ “欢迎逐条验证与反驳”

---

### 2）结构化回应（不是情绪回应）

数学界最怕：

- 争论
- 长篇辩解

👉 要变成：

> 问题 → 精确定位 → 对应证明位置

---

### 3）可追溯（每个问题有编号）

👉 类似 bug tracker，而不是聊天记录

---

## 页面结构（五块）

### 1️⃣ Introduction（开场）

```tsx id="6o15a6"
<h2>Review & Discussion</h2>

<p>
This page documents questions, critiques, and verification attempts
regarding the XPrimes framework.
</p>

<p>
All feedback is welcome. Each item is tracked and addressed in a structured manner.
</p>
```

---

### 2️⃣ Review Protocol（规则声明，极其重要）

```tsx id="27bwqv"
<h3>Review Protocol</h3>

<ul>
  <li>Each critique should reference a specific definition, lemma, or theorem.</li>
  <li>Ambiguous or non-specific objections will not be tracked.</li>
  <li>All responses will point to explicit sections or revisions.</li>
</ul>
```

👉 作用：

> 把“喷子”挡在门外，只留下严肃讨论

---

### 3️⃣ Open Questions（未解决问题）

```tsx id="v6pv55"
<h3>Open Questions</h3>

<ul>
  <li>
    <strong>Q-001</strong><br />
    Concern regarding convergence in Definition 2.1 for large n.<br />
    Status: Under investigation
  </li>
</ul>
```

---

### 4️⃣ Addressed Critiques（已回应）

```tsx id="9avklj"
<h3>Addressed Critiques</h3>

<ul>
  <li>
    <strong>R-001</strong><br />
    Issue: Inconsistency in boundary condition (Theorem 1)<br />
    Response: Clarified in v0.2, Section 3.2<br />
    Status: Resolved
  </li>
</ul>
```

---

### 5️⃣ Submission（外部提交方式）

```tsx id="l6d05z"
<h3>Submit Feedback</h3>

<p>
Please submit critiques via email with the following format:
</p>

<pre>
Subject: XPrimes Review - [Short Title]

Reference:
(e.g., Definition 2.1 / Theorem 3)

Comment:
(clear and specific statement)
</pre>
```

页面读取：

```tsx id="8rl3cc"
import data from '@/data/review.json'

export default function Review() {
    return (
        <div>
            <h2>Review & Discussion</h2>

            {data.map((item) => (
                <div key={item.id}>
                    <strong>{item.id}</strong>
                    <p>{item.title}</p>
                    <p>Reference: {item.reference}</p>
                    <p>Status: {item.status || item.resolution}</p>
                </div>
            ))}
        </div>
    )
}
```

# 四、这个页面真正的“隐藏作用”

这是重点，你要理解：

## 1️⃣ 它在向数学家传递信号：

> “我知道你会找错，而且我已经准备好被你找错”

👉 这是专业态度

---

## 2️⃣ 它降低对方心理成本

普通情况：

- 读论文 → 发现问题 → 不想写邮件 → 放弃

有这个页面：

- 直接提交结构化问题

---

## 3️⃣ 它防止灾难性攻击

没有这个页面：

👉 评论区会变成：

- 情绪攻击
- 无效争论

有这个页面：

👉 所有讨论被“格式化”

---

# 五、你必须避免的3个错误

### ❌ 错误1：写“反驳区”

👉 会被认为是防御性、情绪化

---

### ❌ 错误2：删除负面问题

👉 一旦被发现 = 信誉崩塌

---

### ❌ 错误3：长篇解释

👉 数学家不会看

---
