## 修改 Research 页面（支持版本）

```tsx
const papers = [
    {
        version: 'v0.1',
        date: '2026-04-12',
        file: '/papers/v0.1.pdf',
    },
    {
        version: 'v0.2',
        date: '2026-04-15',
        file: '/papers/v0.2.pdf',
    },
]

export default function Research() {
    return (
        <div>
            <h2>Research Materials</h2>

            <ul>
                {papers.map((p) => (
                    <li key={p.version}>
                        <a href={p.file} target='_blank'>
                            Paper {p.version}
                        </a>{' '}
                        — {p.date}
                    </li>
                ))}
            </ul>
        </div>
    )
}
```

---

👉 作用：

- 每个版本都有时间
- 不覆盖旧版本（非常关键）
- 形成“演化轨迹”

# 四、升级 3：自动更新日志（不用手写）

把 log 改成读取 Git 提交：

## 安装

```bash
npm install gray-matter fs
```

---

## 创建 `/data/logs.md`

```md
---
date: 2026-04-12
---

Initialized project. Defined core structure.

---

## date: 2026-04-13

Refined definition and tested small cases.
```

---

## 修改 Log 页面（动态读取）

```tsx
import fs from 'fs'
import matter from 'gray-matter'

export default function Log() {
    const file = fs.readFileSync('data/logs.md', 'utf-8')
    const entries = file.split('---').filter(Boolean)

    return (
        <div>
            <h2>Research Log</h2>

            {entries.map((entry, i) => {
                const { data, content } = matter(`---${entry}`)
                return (
                    <div key={i}>
                        <strong>{data.date}</strong>
                        <p>{content}</p>
                    </div>
                )
            })}
        </div>
    )
}
```

---

👉 好处：

- 每条 log 都是“结构化记录”
- 可以被追溯
- 比手写 HTML 更严肃

# 五、升级 4：自动部署（CI/CD）

用 GitHub Actions：

## `.github/workflows/deploy.yml`

```yaml
name: Deploy

on:
    push:
        branches:
            - main

jobs:
    build:
        runs-on: ubuntu-latest

        steps:
            - uses: actions/checkout@v3

            - name: Install
              run: npm install

            - name: Build
              run: npm run build
```

👉 如果接 Vercel：

- push 自动部署
- 无需额外配置
